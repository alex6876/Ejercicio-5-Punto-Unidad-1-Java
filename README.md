# 📍 Ejercicio 5 — Representación de un Punto en el Plano


## 📝 Descripción

El sistema permite representar puntos cartesianos en un plano bidimensional $(x, y)$, calcular la distancia Euclidiana respecto al origen $(0,0)$ o a otro punto, y simular el desplazamiento o traslación espacial del punto.

---

## 🚀 Funcionalidades y Requerimientos

### 📦 Clase Punto

* **Atributos:**
  * Coordenada x (Double)
  * Coordenada y (Double)

* **Métodos:**
  * CalcularDistanciaAlOrigen(): Retorna la distancia euclidiana desde el punto actual hasta el origen $(0,0)$.
  * CalcularDistanciaA(otroPunto): Calcula la distancia euclidiana entre el punto actual y otro objeto de tipo `Punto`.
  * Desplazar(dx, dy): Modifica las coordenadas actuales del punto sumando los desplazamientos $\Delta x$ y $\Delta y$.
